【Prefill 完成时】（判断：某 request 的 num_output_tokens == 1，即刚结束 prefill）
  sparse_block_features[req_id] =
      对该请求的每个 KV 块，取块内所有 token 的 Key 向量均值 → [num_blocks, head_dim]

  sparse_query_vectors[req_id] =
      该请求最后一个 prompt token 的 Query 向量 → [head_dim]
      （建议取最后 prefill_topk_query_window 个 Q 的均值，或直接取最后一个）
  # TODO(estimation-zone): sparse_block_value_features[req_id] = 每块 mean V → [num_blocks, head_dim]
【每个 Decode 步结束时】
  sparse_query_vectors[req_id] =
      本步新生成 token 的 Query 向量 → [head_dim]
  sparse_new_block_features[req_id] =
      本步写入的新 KV 块的 mean K → [head_dim]
      （如果块没写满则是当前已有 token 的均值）
  # TODO(estimation-zone): sparse_new_value_features[req_id] = 新块 mean V
=== 关键约定 ===
- block_features 的 feature_dim 建议 = head_dim（各 KV head 的均值）
  或 num_kv_heads * head_dim（展开），选一种后在 SparseKVManager 里统一。
  当前 SparseKVManager 完全透明，feature_dim 由 model_runner 决定。
- SparseAttentionSpec 是在 vllm_config.kv_cache_groups 里配置的，
  model_runner 可通过 isinstance(spec, SparseAttentionSpec) 判断是否启用。
- 所有 sparse_* 字段默认 None，不影响正常 FullAttention 请求。
